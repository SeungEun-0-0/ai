# 성적 CSV 검사기

## ① 무엇을 하나요 (What)

성적 CSV에서 이름과 점수가 올바른 행을 골라내고, 제외한 행은 줄 번호와 이유를 함께 보여 줍니다.

## ② 왜 만들었나요 (Why)

성적표에서 빈 점수를 0점으로 처리하면 실제로 0점을 받은 학생과 구별하기 어렵습니다. 잘못된 행을 그냥 빼 버려도 어느 학생의 점수를 다시 확인해야 할지 알기 어렵습니다. 그래서 읽을 수 있는 성적은 그대로 남기고, 고쳐야 할 행은 원본에서 바로 찾을 수 있게 했습니다.

## ③ 어떻게 쓰나요 (How)

압축을 풀고 `load_scores.py`가 있는 폴더에서 터미널을 엽니다. Python 3가 설치되어 있으면 다음 명령으로 실행할 수 있습니다.

```bash
python load_scores.py scores.csv
```

예제 결과는 유효한 성적 5개, 건너뛴 줄 5개입니다. 김하나의 88점과 91점은 모두 남고, 이두리의 105점은 범위를 벗어나 제외됩니다. 다른 파일을 쓰려면 명령의 `scores.csv`를 해당 파일 이름으로 바꿉니다. 첫 줄은 `name,score`, 다음 줄부터는 이름과 0~100 사이의 정수를 적습니다.

## ④ 어떻게 테스트하나요

두 테스트 모두 이 폴더의 11주차 `load_scores.py`를 검사합니다. A는 10주차 명세서와 최종 코드(v5), B는 11주차 배포 코드의 동작을 정답 기준으로 삼았습니다.

```bash
python -m pip install pytest
python -m pytest -q test_ai_A.py
python -m pytest -q test_ai_B.py
```

두 테스트는 파이썬 기본 도구인 unittest로도 실행할 수 있습니다. 아래 표와 출력은 unittest로 직접 실행한 결과입니다.

```bash
python -m unittest test_ai_A
python -m unittest test_ai_B
```

| 테스트 | 통과 | 실패 |
| --- | ---: | ---: |
| A · 10주차 기준 | 3 | 5 |
| B · 11주차 기준 | 8 | 0 |

B 실행 화면

```text
........
----------------------------------------------------------------------
Ran 8 tests in 0.002s

OK
```

두 기준 모두 0점과 100점, 쉼표가 들어간 이름, 헤더만 있는 파일, 없는 파일을 같은 방식으로 처리합니다. A에서 실패한 다섯 항목은 아래와 같습니다.

| 입력 또는 검사 항목 | A의 기대 결과 (10주차) | B의 기대 결과 및 실제 동작 (11주차) |
| --- | --- | --- |
| 같은 이름의 88점과 91점 | 첫 유효 점수인 88점만 남김 | 두 점수 모두 남김 |
| 빈 줄 | 제외한 줄로 기록 | 기록 없이 넘어감 |
| 제외 기록 한 건 | 줄 번호와 이유를 반환 | 줄 번호, 원본 내용, 이유를 반환 |
| 헤더가 `score,name` | 오류를 알림 | 첫 줄을 건너뛰고 다음 줄을 읽음 |
| 점수가 `7_2` | 잘못된 표기로 보고 제외 | 정수 72로 읽음 |
